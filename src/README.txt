Infnity OS — Arquivos legais (prontos para o projeto)

Conteúdo:
- docs/TERMS_OF_USE.md
- docs/PRIVACY_POLICY.md
- pages/TermsOfUse.tsx
- pages/PrivacyPolicy.tsx

Como usar (sugestão):
1) Copie os .md para uma pasta do projeto (ex.: /docs) se quiser versionar os textos.
2) Copie os .tsx para sua pasta de páginas (ex.: /src/pages) e registre as rotas no seu router (React Router, etc.).
3) Se preferir, você pode renderizar os .md em runtime (MDX/markdown renderer), mas isso é opcional.

Observação:
- Os textos foram feitos para SaaS com 3 planos, amarrando limites/valores ao que estiver exibido na tela de planos no momento da contratação.
